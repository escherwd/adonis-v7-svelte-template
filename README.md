## Adonis + Inertia + Svelte Starter Kit

Created using `create-adonisjs@2` to create an Adonis v6 project with Inertia + Svelte, then manually upgraded to Adonis v7 (Since v7 dropped support for automatic Svelte configuration).

### Getting Started

Clone this repository, install dependancies, and run!

```
npm i
npm run dev
```
